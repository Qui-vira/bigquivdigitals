  Multi-agent healthcare

  MedBand
  -------

  I built a set of agents that take a patient through intake, check the medication and find a pharmacy that actually has it. A licensed person signs off on every answer, and I put that gate in the code itself rather than in a prompt, so it cannot be talked around.

  It is live, and the Python is public. Built for the Band of Agents hackathon, track 3.](https://medband-landing.vercel.app)
* [![Peaceway Online homepage with routes to order on Telegram or check medicine availability.](/_next/image?url=%2Fproof%2Fpeaceway%2F00-homepage-hero.webp&w=3840&q=75)

  Pharmacy commerce and ordering

  Peaceway Online
  ---------------

  My father's pharmacy had no website, so I built him one. Customers, staff and suppliers each get their own way in, people can request medicine and set reminders, and a Telegram bot carries an order from the first search to an itemised confirmation.

  The site is live, the code is public, and there is a real ₦1,055 order on the record.

  My father's pharmacy. I never billed him for it.](/work/peaceway)
* [![The fuel and power page of the Power BI report, with the median price across 37 jurisdictions, the gap between the cheapest and dearest place, and a chart of diesel self-generation against the grid tariff.](/_next/image?url=%2Fproof%2Fnbci%2F02-powerbi-fuel-and-power.webp&w=3840&q=75)

  Cost intelligence and data modelling

  Nigeria Business Cost Intelligence
  ----------------------------------

  Eight Nigerian government agencies publish business costs separately and nobody publishes the combined picture, so I built it. 342 source files hash-verified, cleaned into a PostgreSQL model, then an Excel workbook and a Power BI report on top. It says out loud what it cannot tell you.

  110 analysis checks pass, the database has its own 245-check audit, and both dashboards are validated against the saved file rather than the build log.](/work/nigeria-business-costs)
* [![The PharmaOS sign-in: AI-powered inventory, smart ordering, patient reminders and real-time analytics, built for Nigerian pharmacies.](/_next/image?url=%2Fproof%2Fportfolio%2Fpharmaos.webp&w=3840&q=75)

  Pharmacy operations platform

  PharmaOS
  --------

  The part a customer never sees. Stock, ordering and the daily running of a pharmacy, as a Python backend with a Next.js dashboard on top. I kept the two apart so the shop's internal work can never leak out to the people buying.

  The app is live and both halves of the code are public.](https://pharmaos-frontend.vercel.app)
